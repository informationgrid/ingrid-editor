# HVD

Bei Aktivierung des Merkmals "HVD" wird der Datensatz als "High-Value-Dataset" (HVD), also hochwertiger Datensatz, gekennzeichnet. Dann wird die Angabe mindestens einer HVD-Kategorie verpflichtend. Es können nur Open Data Datensätze als HVD gekennzeichnet werden.
