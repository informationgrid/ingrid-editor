# Output-Daten

Beschreiben Sie alle Daten, die der Algorithmus erzeugt. Geben Sie für jeden Datensatz die benötigten Parameter mit Einheit sowie räumliche und zeitliche Auflösung an, sofern relevant. Falls es bereits veröffentlichte Datensätze aus der Ausführung des Algorithmus gibt, füllen Sie diese in das Feld „URL“ ein. Die Attribute eines Datensatzes können hierbei unterschiedliche räumliche und zeitliche Auflösungen haben, die URL für alle Attribute eines Datensatzes ist gleich.
