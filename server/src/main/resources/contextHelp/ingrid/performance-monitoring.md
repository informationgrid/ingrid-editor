# Performance-Monitoring

Beschreiben Sie, welche Leistung erwartet wird, wie sie gemessen wird, wie häufig sie überprüft wird und wer dafür verantwortlich ist. Nennen Sie die wichtigsten Kennzahlen oder Qualitätskriterien und – sofern vorhanden – Schwellenwerte, bei deren Überschreitung Maßnahmen ergriffen werden.

## Beispiele:

Genauigkeit, Fehlerrate, Laufzeit, Aktualität; monatliche Überprüfung durch das zuständige Fachteam.
