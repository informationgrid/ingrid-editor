# Daten-Bias

Beschreiben Sie bekannte oder vermutete Bias (Verzerrungen) in den Trainingsdaten, z.B. entstanden durch die Datenerhebung oder Stichprobenauswahl. Geben Sie an, welche Maßnahmen zur Erkennung, Bewertung oder Verringerung dieser Verzerrungen getroffen wurden. Falls kein relevanter Bias bekannt ist, sollte dies ebenfalls angegeben werden.
