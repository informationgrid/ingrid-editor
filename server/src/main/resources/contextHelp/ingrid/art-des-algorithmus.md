# Art des Algorithmus

Ordnen Sie den Algorithmus einer der drei Kategorien zu: selbstlernend, regelbasiert oder hybrid. Selbstlernend bedeutet, dass das Verfahren aus Daten lernt; regelbasiert bedeutet, dass festgelegte Regeln die Verarbeitung bestimmen; hybrid kombiniert beide Ansätze.
