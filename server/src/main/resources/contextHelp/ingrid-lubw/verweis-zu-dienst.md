# Information für die Fachredaktionen

Referenz zu OGC-Webdiensten (WMS, WFS, WMTS) zur Darstellung der Geodaten.

## Beispiel:

"WMS Fliessgewässer 1:10.000"

# Information allgemein

OGC-Webdienste, die diesen Geodatensatz referenzieren, werden hier aufgelistet. Die Referenz kann nur im Dienst entfernt werden.

# ISO Abbildung

Die Abbildung wird nur vorgenommen, wenn der gekoppelte Dienst eine Capabilities Methode und eine entsprechende URL definiert hat. Es wird dann die Capabilities URL zusammen mit dem Namen hinterlegt.
