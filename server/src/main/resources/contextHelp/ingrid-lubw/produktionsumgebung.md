# Information für die Fachredaktionen

Auswahlliste. EDV-System oder Fachverfahren, in dem die Daten geführt werden.

## Beispiel:

"Wasserwirtschaftliche Gebiete (WawiG)"

# Information allgemein

In diesem Feld kann die Softwareumgebung, die zur Erstellung des Datensatzes verwendet wurde, eingetragen werden. Dabei kann eine konkrete Software oder aber eine übergeordnetes, komplettes Verarbeitungssystem angegeben werden.

## Beispiel:

"GeoMedia 20XY" oder "QGIS X.Y"

# ISO Abbildung

Beschreibung der Bearbeitungsumgebung, in welcher der Datenbestand erstellt wird, wie Software, Betriebssystem, Dateinamen oder Größe des Datenbestands.
