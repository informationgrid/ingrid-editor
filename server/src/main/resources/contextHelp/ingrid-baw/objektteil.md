# Objektteil

Geben Sie an, welche Objektteile im Modell enthalten sind. Wenn die angegebene Objektart das Modell bereits vollständig beschreibt, kann das Feld leer bleiben. 

Die Auswahlliste basiert auf den Objektteilen des Objektkatalogs der WSV gemäß VV-WSV 1102. Teilweise wurden diese zur weiteren Differenzierung um bauliche Ausprägungen aus den WInD-Fachdatenmodellen ergänzt. Fehlende Objektteile können direkt im Feld eingegeben werden. Nach einer fachlichen Prüfung werden diese in die Auswahlliste aufgenommen.

Zusätzlich wurden folgende Begriffe ergänzt:

Feste Teile: Sammelbegriff für fest mit dem Bauwerk verbundene bzw. einbetonierte Bauteile. Hierzu zählen beispielsweise Auflager, Poller, Platten oder Schienen.

Maschinenteile: Maschinelle Bauteile, die beispielsweise im Rahmen von mechanischen Untersuchungen hinsichtlich ihrer Beanspruchbarkeit betrachtet werden.

Hubportal: Stationäre Bauteile, an denen Hubtore bzw. Hubtorelemente befestigt sind.

Verbindungselement: Bauteile zur Verbindung von Profilen und anderen Bauteilen, insbesondere im Stahlbau. Da Verbindungselemente häufig sehr detailliert modelliert werden müssen, können sie hier als eigene Kategorie erfasst werden.
