# Objektart

Geben Sie an, welche Objektart modelliert wurde bzw. welcher Objektart das Modell zuzuordnen ist. 

Die Auswahlliste basiert auf dem Objektkatalog der WSV gemäß VV-WSV 1102. Fehlende Objektarten können direkt im Feld eingegeben werden. Nach einer fachlichen Prüfung werden diese in die Auswahlliste aufgenommen.
