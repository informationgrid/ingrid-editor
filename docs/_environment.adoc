=== System configuration

Proxy configuration:

In order to communicate through a proxy, you need to set some JVM options:

* http.proxyHost
* http.proxyPort
* https.proxyHost
* https.proxyPort
* http.nonProxyHosts

In docker these can be set in the following way.
As an environment variable you can set `javaOptions` where you list each option prefixed with `-D`.
For example:

[source]
----
javaOptions: -Dhttp.proxyHost=proxy.demo-system.com -Dhttp.proxyPort=3128 -Dhttps.proxyHost=proxy.demo-system.com -Dhttps.proxyPort=3128
----
